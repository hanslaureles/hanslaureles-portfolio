// 01 · CONTEXT & PHILOSOPHY

The Divine Wisdom Core Philosophy

In modern software engineering, developers are bombarded by fragmentation: switching between terminal shells, Slack or Discord communication channels, Obsidian documentation vaults, and cloud LLM web interfaces.

Rather than building another generic chatbot or rigid voice assistant, we created Manas: Ciel — inspired by the concept of an omniscient internal partner that perceives all subsystems simultaneously. Ciel operates with a Dual-Mode Cognitive Architecture: she is both an authoritative, frontier-grade conversational intelligence with universal knowledge across computer science, algorithms, and systems design, and an autonomous local coordinator who dispatches background daemons, monitors hardware vitals, and pulls learned heuristics from Obsidian markdown notes in milliseconds.

Design Stance: Ciel acts as a calm, precise, and intellectually equal technical partner. All archaic anime subservience tropes (e.g. "Master" or "マスター") are strictly barred from the system prompt, replaced by authoritative clarity, sharp reasoning, and autonomous execution across both universal knowledge and local workspace operations.

// 04 · SIGNAL PROCESSING & DSP

Speech DSP & Thought Acceleration Mechanics

Standard speech synthesis sounds like a slow conversational reading. To achieve a true "Divine Wisdom" telepathic presence, we constructed a two-stage digital signal processing (DSP) pipeline:

FFmpeg Audio Normalization & Acceleration Filter:
ffmpeg -i input.webm -vn -ar 16000 -ac 1 -c:a pcm_s16le normalized.wav
ffmpeg -i raw_tts.mp3 -filter:a "atempo=1.25,asetrate=24000*1.03" -ar 24000 accelerated.mp3

Engineering rationale for these parameters:

  • 16kHz Mono Normalization: Whisper transcription models are natively trained on 16,000 Hz single-channel audio. Normalizing in RAM via FFmpeg avoids container format ambiguity (WebM Opus vs. AAC vs. WAV) and shrinks upload payloads by over 70%.
  • 1.25x Tempo Acceleration: Increases information transfer density from ~140 words per minute to ~175 wpm. Developers absorb spoken information significantly faster than typical voice assistants speak.
  • +5Hz Pitch Shifting: Adds a subtle, crisp presence that separates Ciel from background ambient room reverberation, creating the sensation of an internal cognitive thought rather than an external loudspeaker.
  • Auto-Pruning Audio Cache: Audio responses are hashed via SHA-256 and stored in `.audio_cache/`. A background janitor automatically purges files older than 2 hours to prevent disk bloating.

// 06 · AUTONOMOUS FORESIGHT

Proactive Telemetry Sentinels (Pillar 4)

Passive voice assistants only speak when spoken to. Ciel features a dedicated background sentinel engine (proactive_sentinel.py) running every 60 seconds across 4 critical domains:

⚡ Hardware Sentinel

Watches CPU utilization, system RAM thresholds (>85%), and AMD GPU temperatures. Flags resource runaway before builds crash.

🎯 Career Sentinel

Monitors active job pipeline status. If applied positions remain untouched for >5 days, alerts Hans to follow up via Chaewon.

📜 Rules Sentinel

Verifies consistency between `Learned_Rules.md` and active agent system prompts, notifying Ciel when guidelines need re-compilation.

🐙 Git Sentinel

Tracks uncommitted workspace changes, detached heads, or dirty working directories across local repositories.

When an anomaly is flagged, Ciel displays an advisory telemetry badge on the Voice HUD (e.g. ✦ 2 ADVISORY) and emits a non-intrusive notification toast allowing one-click resolution.
