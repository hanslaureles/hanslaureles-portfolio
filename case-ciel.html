// 01 · CONTEXT & PHILOSOPHY

The Divine Wisdom Core Philosophy

In modern software engineering, developers are bombarded by fragmentation: switching between terminal shells, Slack or Discord communication channels, Obsidian documentation vaults, and cloud LLM web interfaces.

Rather than building another generic chatbot or rigid voice assistant, we created Manas: Ciel — inspired by the concept of an omniscient internal partner that perceives all subsystems simultaneously. Ciel operates with a Dual-Mode Cognitive Architecture: she is both an authoritative, frontier-grade conversational intelligence with universal knowledge across computer science, algorithms, and systems design, and an autonomous local coordinator who dispatches background daemons, monitors hardware vitals, and pulls learned heuristics from Obsidian markdown notes in milliseconds.

Design Stance: Ciel acts as a calm, precise, and intellectually equal technical partner. All archaic anime subservience tropes (e.g. "Master" or "マスター") are strictly barred from the system prompt, replaced by authoritative clarity, sharp reasoning, and autonomous execution across both universal knowledge and local workspace operations.

// 04 · SIGNAL PROCESSING & DSP

Speech DSP & Thought Acceleration Mechanics

Standard speech synthesis sounds like a flat conversational reading. To give Ciel a "Divine Wisdom" telepathic presence, the pipeline has two FFmpeg stages, one on the way in and one on the way out:

Inbound (speech-to-text prep), piped in memory:
ffmpeg -i pipe:0 -ar 16000 -ac 1 -af "volume=1.8,highpass=f=80,lowpass=f=7500" -f wav pipe:1
Outbound (Thought Acceleration filter over the JA + EN Edge-TTS clips):
[0:a]apad=pad_dur=0.35[a0];[a0][1:a]concat=n=2:v=0:a=1,highpass=f=120,equalizer=f=3500:t=q:w=1.2:g=3.0,aecho=0.85:0.8:25|45:0.18|0.09,volume=0.30

Engineering rationale for these parameters:

  • 16kHz Mono Normalization: Whisper models are trained on 16,000 Hz single-channel audio. Converting the browser's WebM/Opus recording through stdin/stdout pipes avoids temp files and container ambiguity, and the 80 Hz–7.5 kHz band-pass trims rumble and hiss before transcription.
  • Bilingual Sequencing: The Japanese line plays first, then a 350 ms pause, then the English line, so the two voices read as one deliberate utterance rather than an overlap.
  • Presence, Not Speed: A 120 Hz high-pass removes room boom and a +3 dB lift at 3.5 kHz adds clarity. The voices themselves are tuned slightly lower and slower (−2 to −3 Hz pitch, −1 to −2% rate) for a calm delivery.
  • "Inside the Mind" Echo: Two faint reflections at 25 ms and 45 ms create the sense of an internal thought rather than an external loudspeaker, without the smear of a full reverb.
  • Bounded Audio Cache: Rendered replies are kept in audio_cache/; on server start-up only the 35 most recent files are kept, so the cache can't grow without bound.

// 06 · AUTONOMOUS FORESIGHT

Proactive Telemetry Sentinels (Pillar 4)

Passive voice assistants only speak when spoken to. Ciel features a dedicated background sentinel engine (proactive_sentinel.py) that runs every 45 seconds while the HUD is connected, ranks what it finds (warning > action > info), and surfaces the top 3 across 4 checks:

⚡ Hardware Sentinel

Reads psutil vitals and warns when CPU load passes 85%, RAM passes 88%, or drive C: drops under 20 GB free. Each warning offers a one-click hand-off to Eunchae.

🗓️ Daily Log Sentinel

Opens today's Obsidian daily log. If it's missing, Ciel suggests Sakura's briefing; otherwise it routes the first unchecked priority to the matching agent by keyword.

📄 Portfolio Sentinel

Scans the portfolio's index.html for leftover TODO or FIXME markers and offers a Yunjin audit.

🐙 Git Sentinel

Runs git status --porcelain on the workspace and, at 3 or more uncommitted changes, offers a Kazuha review of the diff.

When an anomaly is flagged, Ciel displays an advisory telemetry badge on the Voice HUD (e.g. ✦ 2 ADVISORY) and emits a non-intrusive notification toast allowing one-click resolution.

// 07 · PIPELINE STAGES & RETROSPECTIVE

Pipeline Stages & Architectural Retrospective

Every voice turn runs through these stages on my workstation (Intel Core i5-12400F, 16GB DDR4, AMD Radeon RX 6600 XT, Windows 11). The p50 column comes from bench/bench_ciel.py in the public repo: N = 10 runs per stage on 2026-10-01. Network stages are round trips from this machine at that time, not compute times. A full mission for a general-knowledge prompt (routing, synthesis and bilingual speech) took 4.43 s p50 (max 5.71 s).

PIPELINE STAGE ENGINE WHAT HAPPENS P50 (N=10)
Audio Normalization FFmpeg Resample to 16kHz mono WAV with loudness leveling and voice-band filtering. 32 ms
Speech-to-Text Groq Whisper Large v3 Turbo → OpenAI whisper-1 Domain-vocabulary prompt; the OpenAI tier runs only if Groq fails. 0.50 s · network
Intent Routing Keyword pre-router + Groq qwen3.8-27b Fast paths for weather, search, and memory reset; the LLM returns a JSON plan for everything else. 0.58 s · network

Retrospective: What Broke & What I Would Change

⚠️ What Broke in V1

Synchronous weather queries to wttr.in and live web search during voice generation caused the audio stream to block and stutter when the user had high internet latency.

→ The Fix (Shipped)

Fixed, and the code is public in lsfm-ai-hq: every blocking call in a mission now runs in a worker thread via asyncio.to_thread: named mission tools (weather, web search, both LLM calls, psutil, Obsidian, git, Gmail, the PDF build) have per-call timeouts, while FFmpeg runs off the event loop without a timeout. The server's event loop keeps serving other clients while a mission waits. Independent agents run concurrently with asyncio.gather. A call that times out ends as an honest failed ("timed out after N s"), never an empty success. At most two missions run at once; a few more queue, and anything beyond that is refused with a 503 instead of flooding the thread pool. Regression tests prove the loop keeps ticking while a tool blocks.

🛠️ Production Architecture Note

While edge-tts provides exceptional low-latency speech synthesis for local developer environments at zero cost, enterprise production deployment would swap it for self-hosted Kokoro/Vits pipelines or dedicated WebRTC audio streaming to satisfy enterprise uptime SLAs.
